# Python Programs Collection

This repository contains beginner-friendly Python programs created for practice and learning.

## Programs Included

1. **Factorial** – Calculates the factorial of a number.
2. **Fibonacci Series** – Generates the first `n` Fibonacci numbers.
3. **Structure to Dictionary** – Converts field names and values into a Python dictionary.

## Technologies Used

* Python 3

## How to Run

1. Install Python 3 on your computer.
2. Open a terminal in the project folder.
3. Run the following command:

   `python main.py`
